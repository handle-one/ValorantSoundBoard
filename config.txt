# 输出设备：按名称匹配一个“输出”设备（虚拟声卡）。
# 留空 = 使用系统默认输出设备（测试用，声音会从音箱出来）。
# 装 Voicemeeter 后写 Voicemeeter，声音就只进 Voicemeeter 混音台，不进音箱。
device = Voicemeeter

# 自动按住 PTT 键：播放声音期间自动按下并松开这个键，
# 适合游戏语音是“按住说话”模式。不需要就删掉这一行。
# ptt_key = V

# 停止键：按它立刻停掉正在播放的声音（程序不退出）。
# 写法同热键（F1~F24 / A~Z / 0~9，可加 CTRL+ / SHIFT+ / ALT+）。
# 注意：这个键不能同时配给声音。
