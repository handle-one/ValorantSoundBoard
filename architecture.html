ValoSoundBoard 架构与数据流
示意：从“按热键”到“队友听到”的完整链路
① 你的 C++ 程序（ValoSoundBoard.exe）
按 F6（游戏全屏也行）
RegisterHotKey 已把 F6 注册为全局热键，系统随时能认出它
▶
收到 WM_HOTKEY 消息
主循环 GetMessage 取出消息，按消息编号查表
▶
查表：F6 → example.wav
g_bindings 是“热键 id → 音频文件”的数组，O(1) 查表
▶
MF 拓扑：解码 → 渲染
媒体源节点(解码文件) → 音频渲染器节点(指定输出设备 ID)
▼
② 系统音频层（VB-CABLE 虚拟声卡）
CABLE Output（输出端）
程序的声音只送来这里，不会从音箱出声打扰自己
▶
内部跳线
虚拟声卡把 Output 的音频信号直接接到 Input 端
▶
CABLE Input（输入端）
系统把它当成一个麦克风，任何程序都能选它当录音/语音输入
▼
③ 无畏契约
语音输入设备 = CABLE Input
在 设置→音频→语音 里把麦克风改成虚拟声卡的输入端
▶
队内语音播放
你按 F6 播放的音效，此刻就从“麦克风”进了语音，队友听到
补充说明
· 核心思想：游戏只认“麦克风输入设备”，而 CABLE Input 就是程序输出的另一端，声音绕开了真实扬声器直接进语音。
· 可选：配置 ptt_key = V 后，播放期间程序自动按住“说话键”（默认关闭）。
· 保留热键：F5 重新加载配置，Ctrl+Q 退出。
· 没装 VB-CABLE 时，把配置里 device 留空，声音先走默认音箱，用于测试。
